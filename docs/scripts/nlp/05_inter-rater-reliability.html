How Closely the Models Match Bree’s Coding

Author

Manuel Alcalá Kovalski, Urban Institute

Published

November 4, 2026

Bree coded the canvassing and survey files in her September sample in NVivo with codebook version 5, 71 open-ended answers in all. We compared her codes with the codes Sonnet and Opus gave the same answers, counting only codes from version 5 so that all three coders choose from the same list. The last section has a short write-up of the methods and results for the qualitative researcher memo.

64 of the 71 answers respond to one canvassing question: “What’s one thing you would change about care, whether it’s for your kids, aging family members, people with disabilities, yourself, or the people around you? (Optional)” The other 7 are survey answers.

Sonnet matches Bree as well as Opus does

Sonnet agrees with Bree as closely as Opus does and costs less than half as much per answer ($0.0047 versus $0.0101), so Sonnet is probably the way to go.

# share of codes in common: both empty counts as identical
jaccard <- function(a, b) {
  either <- union(a, b)
  if (length(either) == 0) return(1)
  length(intersect(a, b)) / length(either)
}

# MASI distance (Passonneau 2006): 0 = identical sets, 1 = nothing in common.
# Shared share of codes, weighted by how the sets overlap: identical 1, one
# contains the other 2/3, partial overlap 1/3, none 0
masi_distance <- function(a, b) {
  if (length(union(a, b)) == 0) return(0)
  shared <- length(intersect(a, b)) / length(union(a, b))
  weight <- if (setequal(a, b)) 1
    else if (all(a %in% b) || all(b %in% a)) 2 / 3
    else if (length(intersect(a, b)) > 0) 1 / 3
    else 0
  1 - shared * weight
}

# distance between every pair of code sets, filled once so the bootstrap only
# indexes into it
distance_matrix <- function(sets, distance) {
  n <- length(sets)
  d <- matrix(0, n, n)
  for (i in seq_len(n - 1)) {
    for (j in (i + 1):n) d[i, j] <- d[j, i] <- distance(sets[[i]], sets[[j]])
  }
  d
}

# Krippendorff's alpha for two coders: 1 - observed / expected disagreement.
# `d` holds the first coder's sets, then the second's, so answer i is row i
# and row n + i. Observed: the two coders on the same answer. Expected: any
# two sets drawn from all the sets both coders produced.
alpha_from_distances <- function(d, idx) {
  n <- nrow(d) / 2
  pooled <- c(idx, n + idx)
  observed <- mean(d[cbind(idx, n + idx)])
  m <- length(pooled)
  expected <- sum(d[pooled, pooled]) / (m * (m - 1))
  1 - observed / expected
}

# the three measures for two coders, each with a 95 percent bootstrap interval
pair_agreement <- function(x, y) {
  both <- lengths(map2(x, y, intersect))
  d <- distance_matrix(c(x, y), masi_distance)
  measures <- function(idx) {
    c(
      found  = sum(both[idx]) / sum(lengths(x)[idx]),
      agreed = sum(both[idx]) / sum(lengths(y)[idx]),
      alpha  = alpha_from_distances(d, idx)
    )
  }
  estimate <- measures(seq_along(x))
  boot <- replicate(n_boot, measures(sample(length(x), replace = TRUE)))
  tibble(
    measure = names(estimate),
    estimate,
    low  = apply(boot, 1, quantile, 0.025),
    high = apply(boot, 1, quantile, 0.975)
  )
}

show <- function(r, what) {
  r <- filter(r, measure == what)
  if (what == "alpha") sprintf("%.2f (%.2f–%.2f)", r$estimate, r$low, r$high)
  else sprintf("%.0f%% (%.0f–%.0f)", 100 * r$estimate, 100 * r$low, 100 * r$high)
}

95 percent intervals in brackets, from resampling the answers 2,000 times.

  • Each model finds about half of Bree’s codes, and alpha is 0.25 for both. On Bree’s scale, that is fair agreement, well below the substantial agreement (0.7 to 0.8) we were hoping for. Most of the difference comes down to the two issues in the next section.
  • The two models agree with each other about twice as much (alpha 0.52, moderate agreement). The gap with Bree comes from how the task is set up, not from which model does it.

What drives the disagreement

1. The models code every topic an answer mentions; Bree appears to code only the answer to the question. The models use 2.2 to 2.4 codes per answer, compared with 1.7 for Bree. Most of the extras are on topics Bree did not code on that answer, such as the hardship someone describes when asked what they would change. Leaving those out, about 7 in 10 model codes match hers. This explains about half the gap, and Bree’s answer on which rule she follows tells us which rule to give the models.

2. Two codes account for about half of what the models miss. Of the codes Bree chose that a model did not, 47% to 48% are NEED_HIGH_QUALITY_CARE or NEED_OTHER. Bree uses NEED_HIGH_QUALITY_CARE for answers about caregiver pay, where the models choose SOLUTION_CAREGIVER_WAGES, and NEED_OTHER where the models find a specific code. Where the line falls between these codes is a question for Bree.

Text for the memo

To copy into the qualitative researcher memo and edit.

To check how closely the NLP coding matches human coding, Manu compared Bree’s NVivo coding of the September 22 random selection, 71 open-ended answers (64 from the canvass export and 7 from the open-ended survey export), with the coding of the same answers by two large language models, Claude Sonnet 5 and Claude Opus 5.5. The models were given codebook version 6 and written coding rules and did not see Bree’s codes. The 22 codes added in version 6 were set aside, so all three coders chose from the same 145 codes. NVivo exports do not include respondent IDs, so coded passages were matched to answers by text. Because an answer can carry several codes, agreement was measured on each answer’s full set of codes with Krippendorff’s alpha using the MASI distance (Passonneau, 2006), with 95 percent confidence intervals from resampling the answers.

Coders Krippendorff’s alpha Share of Bree’s codes found
Bree and Sonnet 0.25 (0.17–0.33) 52%
Bree and Opus 0.25 (0.17–0.33) 48%
Sonnet and Opus 0.52 (0.42–0.61)

Agreement between Bree and each model was fair (alpha = 0.25; Landis & Koch, 1977), below the 0.75 threshold. The two models agreed with each other at a moderate level (alpha = 0.52), and Sonnet matched Bree as closely as Opus at less than half the cost. Two patterns explain most of the gap. The models coded every topic an answer mentioned (2.2 to 2.4 codes per answer, compared with 1.7 for Bree), whereas Bree appears to code only the content that answers the question; limited to the topics Bree coded, alpha rises to 0.34. And about half the codes the models missed were NEED_HIGH_QUALITY_CARE, where the models chose SOLUTION_CAREGIVER_WAGES, or NEED_OTHER, where they chose a more specific code. Next, Bree will set rules for both, Manu will add them to the coding prompt and codebook, and the models will recode the same 71 answers.
