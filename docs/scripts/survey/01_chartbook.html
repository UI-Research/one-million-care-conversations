1M Care Conversations: preliminary chartbook

Author

Manuel Alcalá Kovalski, Urban Institute

Published

September 22, 2026

This chartbook is a first look at who the 1M Care Conversations campaign is reaching and what people are saying. It covers all deliveries received so far, through September 1, 2026. Counts here will be lower than the coalition’s own running totals, because deliveries to Urban lag the live forms.

Three things to keep in mind while reading:

  • The three tools (the digital survey, canvassing, and interviews) are shown separately throughout and never added together. They reach different people in different ways.
  • These are the people who chose to respond. The numbers describe them, not the country.
  • Survey counts include people who stopped partway through. Each chart says which respondents it is based on.

The data were cleaned by scripts/01_clean-data.qmd, which explains how the raw exports were handled.

Where responses come from

The survey asks for a ZIP code at the start of the demographic section, so we have one for 2034 of the 2872 survey respondents (the rest stopped before that point). Canvassing records the canvasser’s ZIP, not the respondent’s, so it tells us where conversations happened. Interviews are placed by the ZIP in each transcript’s header; a group session carries one ZIP for everyone in the room, and one transcript has no ZIP at all.

Show code 
# USDA ERS 2020 Rural-Urban Commuting Area codes by ZIP code (Sept 2025
# release). Gives each ZIP its state and a 1-10 rurality code. Downloaded
# once into data/raw/reference/ (not committed).
ruca_path <- here("data/raw/reference/ruca2020_zip.csv")
if (!file.exists(ruca_path)) {
  dir.create(dirname(ruca_path), showWarnings = FALSE)
  download.file(
    "https://www.ers.usda.gov/media/5444/2020-rural-urban-commuting-area-codes-zip-codes.csv",
    ruca_path, headers = c("User-Agent" = "Mozilla/5.0")
  )
}
zip_lookup <- read_csv(ruca_path, col_types = cols(.default = "c")) |>
  transmute(zip = ZIPCode, state = State, ruca = as.integer(PrimaryRUCA))
zip_state <- select(zip_lookup, zip, state)

# a few people typed ZIP+4 ("97530-0524"); the first five digits are the ZIP
survey_state <- survey |>
  filter(!is.na(zip)) |>
  mutate(zip = str_sub(zip, 1, 5)) |>
  left_join(zip_lookup, by = "zip")

canvassing_state <- canvassing |>
  filter(!is.na(canvasser_zip)) |>
  left_join(zip_state, by = c("canvasser_zip" = "zip"))

# adults (18+) per state from the ACS 2024 1-year, pulled once and cached
# like the national benchmarks below
acs_state_path <- here("data/raw/reference/acs2024_state_adults.csv")
if (!file.exists(acs_state_path)) {
  tidycensus::get_acs(
    "state", variables = sprintf("B01001_%03d", c(7:25, 31:49)),
    year = 2024, survey = "acs1"
  ) |>
    summarise(adults = sum(estimate), .by = NAME) |>
    rename(state_name = NAME) |>
    write_csv(acs_state_path)
}
state_adults <- read_csv(acs_state_path, show_col_types = FALSE) |>
  filter(state_name != "Puerto Rico") |>
  mutate(share_us_adults = adults / sum(adults))

# The Century Foundation's 2024 care-policy report card grade for each state
# (Gutierrez et al. 2024), as tabulated in the Population Data Memo; entered
# by hand because the report card is not available as data
care_grades <- read_csv(here("data/raw/reference/care_policy_grades_2024.csv"), show_col_types = FALSE)
failing_grades <- c("F", "D-", "D", "D+")

state_counts <- list(
  survey = survey_state,
  canvassing = canvassing_state,
  interviews = interview_state
) |>
  imap(\(data, tool) count(filter(data, !is.na(state)), state, name = tool)) |>
  reduce(full_join, by = "state") |>
  full_join(states, by = "state") |>
  mutate(
    state_name = coalesce(state_name, state),
    across(c(survey, canvassing, interviews), \(x) replace_na(x, 0L))
  ) |>
  left_join(care_grades, by = "state_name") |>
  left_join(select(state_adults, state_name, share_us_adults), by = "state_name") |>
  mutate(share_survey = survey / sum(survey)) |>
  arrange(desc(survey), state_name)

share_failing <- \(x) sum(x[state_counts$care_policy_grade %in% failing_grades]) / sum(x)

Every state is listed, including those with no responses yet, so gaps are visible. Two columns give the comparison that matters for outreach: each state’s share of all survey respondents next to its share of US adults, so a state with a much smaller survey share than population share is one the campaign is under-reaching. The grade is the state’s score on the Century Foundation’s 2024 care-policy report card, which the coalition’s outreach guidance uses to prioritize states with D and F grades. Those states hold 61% of US adults and 47% of survey respondents so far. Click a column heading to sort.

Rural and urban

The same ZIP lookup classifies each ZIP code by how rural it is, using the Rural-Urban Commuting Area (RUCA) codes from the USDA Economic Research Service. The codes run from 1 (inside a metropolitan area) to 10 (rural, far from any town), based on where people in that ZIP commute to work. We group them two ways: a four-way split used in much rural health research, and the urban/rural split the coalition asked for (Jaimie Worker, CAG, September 2026), where “rural” is RUCA 4 to 10. That is also the cut the Health Resources and Services Administration’s Federal Office of Rural Health Policy uses to define rural for its programs.

Show code 
survey_state <- survey_state |>
  mutate(
    rurality = case_when(
      ruca %in% 1:3  ~ "Metropolitan (1-3)",
      ruca %in% 4:6  ~ "Micropolitan (4-6)",
      ruca %in% 7:9  ~ "Small town (7-9)",
      ruca == 10     ~ "Rural (10)"
    ) |> factor(levels = c("Metropolitan (1-3)", "Micropolitan (4-6)", "Small town (7-9)", "Rural (10)")),
    urban_rural = if_else(ruca %in% 1:3, "Urban (RUCA 1-3)", "Rural (RUCA 4-10)") |>
      factor(levels = c("Urban (RUCA 1-3)", "Rural (RUCA 4-10)"))
  )

survey_state |>
  filter(!is.na(rurality)) |>
  count(urban_rural, rurality, name = "respondents") |>
  mutate(share = percent(respondents / sum(respondents), accuracy = 1)) |>
  rename("Urban or rural" = urban_rural, "RUCA group" = rurality) |>
  tbl()

One check on that definition. RUCA codes 2 and 3 are places within commuting range of a metropolitan core but outside it — suburbs and exurbs — and whether they count as urban or rural is a judgment call. The same question split three ways shows whether that choice matters: if the middle column looks like the first, the definition above is safe; if it looks like the last, counting 2 and 3 as rural would change the picture.

Compared with US adults

To see who the campaign is reaching and missing, each characteristic is set next to the same figure for the country, from the Census Bureau’s American Community Survey (2024 one-year estimates). This is context, not a claim that the survey resembles the population: respondents chose to take part, and the gaps are the point. “Prefer not to say” answers are left out of the survey shares here so the two columns add up the same way.

Some survey categories do not line up with the Census exactly; each table says how they were matched. Disability and political views are not compared: the Census defines disability differently, and there is no Census measure of political views.

Connection to care

The first question asks about a person’s connection to care and routes them to one of five pathways. This decides which questions each person sees, so it shapes everything below. Current caregivers and care recipients are by far the largest group.

Canvassing

Canvassing is a doorstep conversation, so it is a funnel: not everyone approached answers, not everyone who answers has a connection to care, and not everyone with a connection agrees to the full questions. Each stage is a different base for any analysis.

Show code 
funnel <- tibble(
  stage = c(
    "Approached",
    "Answered and engaged",
    "Reports a connection to care",
    "Agreed to full questions"
  ),
  n = c(
    nrow(canvassing),
    sum(canvassing$responded == "Yes - continue with questions", na.rm = TRUE),
    sum(canvassing$care_connection == "Yes", na.rm = TRUE),
    sum(!is.na(canvassing$pathway))
  )
) |>
  mutate(stage = fct_rev(fct_inorder(stage)))

ggplot(funnel, aes(n, stage)) +
  geom_col() +
  geom_text(aes(label = n), hjust = -0.5, size = 3) +
  scale_x_continuous(expand = expansion(mult = c(0, .1))) +
  labs(title = "Canvassing doorstep funnel", x = "Contacts", y = NULL)

The revised form (August on)

In August the coalition changed the canvassing form: the yes/no connection-to-care question and the challenge checklist were replaced by “Do you need care or is there someone in your life you help take care of?” and a free-text “What’s been hard about that?” There are three versions of the revised form, with different questions; almost all responses so far come from the Daisy Chain event (c2), which asked only the two new questions.
