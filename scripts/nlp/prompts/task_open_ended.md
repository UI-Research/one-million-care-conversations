## Task: written answers to one open-ended question
You will receive the question as the respondent saw it, then several answers, each
with a passage_id and (when known) the respondent's pathway through the survey
(current = currently gives or receives care, past = did in the past, future = expects
to, observer = sees it in others, none). Code each answer independently: nothing in
one answer informs another.

The pathway is context for resolving tense and role, not a source of content: do not
assign a Participant Characteristics code from the pathway alone. Answers are short
and written, so many will carry one or two codes and some none at all. Do not stretch
a code to fill an answer. Return an entry for every passage_id you were given, with an
empty codes list where nothing applies.
