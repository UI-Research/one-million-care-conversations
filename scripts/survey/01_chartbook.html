1M Care Conversations: preliminary chartbook

Author

Manuel Alcalá Kovalski, Urban Institute

Published

October 1, 2026

This chartbook is a first look at who the 1M Care Conversations campaign is reaching and what people are saying. It covers responses received through September 1, 2026.

Three things to keep in mind while reading:

  • The three tools (the digital survey, canvassing, and interviews) are shown separately throughout and never added together. They reach different people in different ways.
  • These are the people who chose to respond. The numbers shown here describe respondents and are not nationally representative.
  • Survey counts include people who stopped partway through. Each chart says which respondents it is based on.

The Cleaning page explains how the raw exports were handled.

Where responses come from

The survey asks for a ZIP code at the start of the demographic section, so we have one for 2034 of the 2872 survey respondents (the rest stopped before that point). Canvassing records the canvasser’s ZIP, not the respondent’s, so it tells us where conversations happened. Interviews are placed by the ZIP in each transcript’s header; a group session carries one ZIP for everyone in the room, and one transcript has no ZIP at all.

Show code 
# USDA ERS 2020 Rural-Urban Commuting Area codes by ZIP code (Sept 2025
# release). Gives each ZIP its state and a 1-10 rurality code. Downloaded
# once into data/raw/reference/ (not committed).
ruca_path <- here("data/raw/reference/ruca2020_zip.csv")
if (!file.exists(ruca_path)) {
  dir.create(dirname(ruca_path), showWarnings = FALSE)
  download.file(
    "https://www.ers.usda.gov/media/5444/2020-rural-urban-commuting-area-codes-zip-codes.csv",
    ruca_path, headers = c("User-Agent" = "Mozilla/5.0")
  )
}
zip_lookup <- read_csv(ruca_path, col_types = cols(.default = "c")) |>
  transmute(zip = ZIPCode, state = State, ruca = as.integer(PrimaryRUCA))
zip_state <- select(zip_lookup, zip, state)

# a few people typed ZIP+4 ("97530-0524"); the first five digits are the ZIP
survey_state <- survey |>
  filter(!is.na(zip)) |>
  mutate(zip = str_sub(zip, 1, 5)) |>
  left_join(zip_lookup, by = "zip")

canvassing_state <- canvassing |>
  filter(!is.na(canvasser_zip)) |>
  left_join(zip_state, by = c("canvasser_zip" = "zip"))

# The Century Foundation's 2024 care-policy report card grade for each state
# (Gutierrez et al. 2024), as tabulated in the Population Data Memo; entered
# by hand because the report card is not available as data
care_grades <- read_csv(here("data/raw/reference/care_policy_grades_2024.csv"), show_col_types = FALSE)
failing_grades <- c("F", "D-", "D", "D+")

state_counts <- list(
  survey = survey_state,
  canvassing = canvassing_state,
  interviews = interview_state
) |>
  imap(\(data, tool) count(filter(data, !is.na(state)), state, name = tool)) |>
  reduce(full_join, by = "state") |>
  full_join(states, by = "state") |>
  mutate(
    state_name = coalesce(state_name, state),
    across(c(survey, canvassing, interviews), \(x) replace_na(x, 0L))
  ) |>
  left_join(care_grades, by = "state_name") |>
  left_join(select(state_adults, state_name, share_us_adults), by = "state_name") |>
  mutate(share_survey = survey / sum(survey)) |>
  arrange(desc(survey), state_name)

share_failing <- \(x) sum(x[state_counts$care_policy_grade %in% failing_grades]) / sum(x)

Every state is listed, including those with no responses yet, so gaps are visible. Two columns give the comparison that matters for outreach: each state’s share of all survey respondents next to its share of US adults, so a state with a much smaller survey share than population share is one the campaign is under-reaching. The grade is the state’s score on the Century Foundation’s 2024 care-policy report card, which the coalition’s outreach guidance uses to prioritize states with D and F grades. Those states hold 61% of US adults and 47% of survey respondents so far. Click a column heading to sort.

grade_band <- \(grade) case_when(
  grade %in% c("F", "D-", "D", "D+") ~ "D or F",
  grade %in% c("C-", "C", "C+")      ~ "C",
  grade %in% c("B-", "B", "B+")      ~ "B",
  TRUE                               ~ "not graded"
)
summarise_states <- function(data, by) {
  data |>
    summarise(
      States = n(), Survey = sum(survey),
      `Share of survey` = sum(share_survey), `Share of US adults` = sum(share_us_adults),
      Canvassing = sum(canvassing), Interviews = sum(interviews),
      .by = {{ by }}
    ) |>
    mutate(across(starts_with("Share"), \(x) percent(x, accuracy = 1)))
}

state_counts |>
  mutate(`Care-policy grade` = factor(grade_band(care_policy_grade), levels = c("D or F", "C", "B", "not graded"))) |>
  summarise_states(`Care-policy grade`) |>
  arrange(`Care-policy grade`) |>
  tbl("Responses by care-policy grade")

Rural and urban

The same ZIP lookup classifies each ZIP code by how rural it is, using the Rural-Urban Commuting Area (RUCA) codes from the USDA Economic Research Service. The codes run from 1 (inside a metropolitan area) to 10 (rural, far from any town), based on where people in that ZIP commute to work. We group them two ways: a four-way split used in much rural health research, and the urban/rural split the coalition asked for (Jaimie Worker, Caring Across Generations, September 2026), where “rural” is RUCA 4 to 10. That is also the cut the Health Resources and Services Administration’s Federal Office of Rural Health Policy uses to define rural for its programs.

Show code 
survey_state <- survey_state |>
  mutate(
    rurality = case_when(
      ruca %in% 1:3  ~ "Metropolitan (1-3)",
      ruca %in% 4:6  ~ "Micropolitan (4-6)",
      ruca %in% 7:9  ~ "Small town (7-9)",
      ruca == 10     ~ "Rural (10)"
    ) |> factor(levels = c("Metropolitan (1-3)", "Micropolitan (4-6)", "Small town (7-9)", "Rural (10)")),
    urban_rural = if_else(ruca %in% 1:3, "Urban (RUCA 1-3)", "Rural (RUCA 4-10)") |>
      factor(levels = c("Urban (RUCA 1-3)", "Rural (RUCA 4-10)"))
  )

survey_state |>
  filter(!is.na(rurality)) |>
  count(urban_rural, rurality, name = "respondents") |>
  mutate(share = percent(respondents / sum(respondents), accuracy = 1)) |>
  rename("Urban or rural" = urban_rural, "RUCA group" = rurality) |>
  tbl()

Rural respondents are a smaller group, so splits within the rural categories are still thin. The urban/rural split is large enough to compare answers under the project’s subgroup standard (200 or more respondents per group). For example, what ideal care looks like:

One check on that definition. RUCA codes 2 and 3 are places within commuting range of a metropolitan core but outside it (suburbs and exurbs), and whether they count as urban or rural is a judgment call. The same question split three ways shows whether that choice matters: if the middle column looks like the first, the definition above is safe; if it looks like the last, counting 2 and 3 as rural would change the picture.

Show code

    ruca >= 4        ~ "RUCA 4-10 (rural)"

What ideal care would look like

Everyone sees this question regardless of pathway, so it has the widest base. It asks people to choose up to three answers, but the form does not enforce that: roughly four in ten respondents chose more, and some chose all eleven. The table shows shares two ways, among everyone and among only the people who kept to three or fewer. The order of the answers is nearly the same either way; what changes is how big the percentages are, and it is worth deciding which version to report.

Ideal care by respondent group

The same question, split by age, disability, household income, household size, and race and ethnicity. Each column is one group; the number in the heading is how many people in that group answered. The splits with few groups are also drawn as charts; the many-column splits are tables only. These splits follow the project’s standard for reporting on subgroups: a group with fewer than 50 respondents is not shown, a group with 50 to 199 is marked “interpret with caution,” and a group with 200 or more is reported plainly. In their own words

Every choose-all-that-apply question has an “Other” box. Text written there is kept word for word and will be coded alongside the open-ended questions. Number of respondents who wrote something, by question:

Show code 
survey |>
  select(ends_with("_other_text")) |>
  summarise(across(everything(), \(x) sum(!is.na(x)))) |>
  pivot_longer(everything(), names_to = "question", values_to = "respondents") |>
  mutate(question = str_remove(question, "_other_text")) |>
  filter(respondents > 0) |>
  arrange(desc(respondents)) |>
  tbl()

Canvassing

Canvassing is a conversation, so it is a funnel: not everyone approached answers, and not everyone who answers has a connection to care. Each stage is a different base for any analysis.

Show code 
funnel <- tibble(
  stage = c(
    "Approached",
    "Answered and engaged",
    "Reports a connection to care"
  ),
  n = c(
    nrow(canvassing),
    sum(canvassing$responded == "Yes - continue with questions", na.rm = TRUE),
    sum(canvassing$care_connection == "Yes", na.rm = TRUE)
  )
) |>
  mutate(stage = fct_rev(fct_inorder(stage)))

ggplot(funnel, aes(n, stage)) +
  geom_col() +
  geom_text(aes(label = n), hjust = -0.5, size = 3) +
  scale_x_continuous(expand = expansion(mult = c(0, .1))) +
  labs(title = "Canvassing funnel", x = "Contacts", y = NULL)

During the conversation, the canvasser records challenges from a short list before the full questions begin. This covers everyone who engaged, not just those who went on to the full questions.

The revised form (August on)

In August the coalition changed the canvassing form: the yes/no connection-to-care question and the challenge checklist were replaced by “Do you need care or is there someone in your life you help take care of?” and a free-text “What’s been hard about that?” There are three versions of the revised form, with different questions; almost all responses so far come from the Daisy Chain event (c2), which asked only the two new questions. Because the questions differ, these contacts are kept apart from the funnel and challenge charts above.
