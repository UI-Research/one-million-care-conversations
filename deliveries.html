Deliveries

What the coalition has sent, month by month, checked against the team’s data log

Caring Across Generations sends data as a batch of files, roughly once a month, and records every file in a log on Box: what it is, when it was delivered, what dates it covers, and whether it has been checked for personal information. The sync step reads that log, and everything on this page comes from it. The register lists every file received; the grid below it is the team’s own month-by-month view of what has arrived, with an automatic check that it matches the files we actually hold.

Does the grid match the files we hold?

Each “Received” cell should correspond to a file in the register whose data cover that month, and every file in the register should have its cell marked. Rows the check can read are the survey and canvassing rows (a form number, closed or open text, complete or partial); interviews and the pre-launch poll are counted by tool. Cells listed below are worth a look rather than errors: so far they come from a collection window logged as a single day, one logged as “Unknown”, and a file whose logged dates run into the following month.
